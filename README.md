# 安琪放映室 · 第三方桌面客户端

> 当前状态：**骨架阶段，尚未发布任何可用版本**。本仓库是公开发布出口，不是源码仓库。

安琪放映室（AngelScreening）是一款自研的跨平台桌面客户端，面向飞牛影视服务，
提供登录、媒体库浏览、直链与 HLS 播放、硬件解码与字幕支持，
覆盖 Windows / macOS / Linux（x64 与 arm64）。
界面与交互为独立原创设计，不模仿任何一方现有客户端。

**名称说明**：本项目是连接用户自有服务的桌面播放客户端，与其他使用「安琪」字样的应用没有任何关联。

**内容边界**：本项目不内置、不运营、不分发任何在线内容。客户端提供可选的第三方数据接入能力；是否启用、接入何种来源、以及由此产生的全部责任，均由用户自行判断与承担。项目不对任何第三方内容负责。
